## Claude Code

- Общая документация проекта — в `AGENTS.md` (импортирован выше). Правила Expo для `apps/web` — в `apps/web/AGENTS.md`.
- **Параллельная работа с субагентами.** Сначала фиксируйте контракт в `packages/shared`: типы, шапку `api.ts`, тесты движка. Затем давайте субагентам узкие задачи по непересекающимся файлам, например web-клиент, генератор трафика, сервер. Запрещайте им менять чужие файлы и контракт: предложения по контракту пусть возвращают в отчёте. Принимайте результат только после typecheck, тестов и чтения диффа.
- **Процессы.** Не убивайте процессы по широкому шаблону вроде `pkill -f "tsx src/index.ts"`: так однажды был убит сервер параллельного агента. Останавливайте по порту: `lsof -tiTCP:<port> -sTCP:LISTEN | xargs kill`.
- **Временные файлы.** Одноразовые БД и скрипты кладите в scratchpad-директорию сессии, не в `apps/server/data`.
- **Railway CLI.** CLI v5 может упасть с panic в `railway volume add`, если сервис не привязан. Сначала выполните `railway link -p <project> -e production -s web`.
- **Коммиты.** Коммитить и пушить только по просьбе пользователя, в `main` репозитория `ssavl/test-saveliistepura`.
